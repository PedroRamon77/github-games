## Welcome to GitHub Games

A project based learning activity for people who are getting started with Git and GitHub.

## Neon Tetris

Versão do Tetris mantida pela equipe neste fork. As peças caem no tabuleiro e o objetivo é completar linhas para pontuar; a partida termina quando a pilha chega ao topo.

Não há versão online deste fork: o GitHub Pages não está ativado. Para jogar, siga a seção [Como executar o jogo localmente](#como-executar-o-jogo-localmente). O endereço https://githubschool.github.io/github-games/ é o jogo original do treinamento, sem as mudanças da equipe.

>> _*SUPPORTED BROWSERS*: Chrome, Firefox, Safari, Opera and IE9+_

This fun open source game was cloned from: https://github.com/jakesgordon/javascript-tetris

## Controles

| Tecla | Ação |
| --- | --- |
| ← / → | move a peça para a esquerda ou para a direita |
| ↑ | gira a peça |
| ↓ | acelera a descida da peça |
| Enter | derruba a peça na hora (queda instantânea) |
| Espaço | inicia, pausa ou continua a partida |
| Esc | encerra a partida |

Os controles também aparecem no botão **Controles**, no menu do jogo.

## Funcionalidades adicionadas pela equipe

- **Peça fantasma:** mostra onde a peça vai cair, com efeito de pulsação.
- **Alerta de perigo:** avisa quando a pilha fica alta (atenção a partir de 11 linhas de altura, perigo a partir de 15).
- **Tela de Game Over:** tela cheia com pontuação, recorde e botão "JOGAR NOVAMENTE".
- **Recorde:** a maior pontuação fica salva no navegador, com aviso de novo recorde.
- **Visual novo:** layout modernizado, ícones nos indicadores e peças em formato de esfera.
- **Janela de controles:** botão "Controles" com as instruções do jogo.
- **Queda instantânea:** tecla Enter.

## Como executar o jogo localmente

1. Clone ou baixe o repositório da equipe: https://github.com/PedroRamon77/github-games
2. Abra a pasta do repositório no seu computador.
3. Dê dois cliques no arquivo `inde.html` ou abra esse arquivo diretamente no navegador.

O nome correto do arquivo é `inde.html`, sem a letra "x".
